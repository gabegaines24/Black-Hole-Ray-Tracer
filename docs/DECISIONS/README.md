# Architecture decisions

Accepted decisions constrain implementation beyond equations and type contracts.
Each record names consequences and evidence.

| ADR | Decision |
|---|---|
| [ADR-001](ADR-001-canonical-phase2-c-api.md) | Keep one canonical Phase 2 C scalar/batch implementation |
| [ADR-002](ADR-002-kerr-zamo-camera.md) | Use a Kerr ZAMO/local orthonormal camera |
| [ADR-003](ADR-003-disk-crossing-observables.md) | Define disk hits from first strict sign-changing crossings |
| [ADR-004](ADR-004-ml-experimental-boundary.md) | Keep ML opt-in, schema-validated, and fallback-safe |
| [ADR-005](ADR-005-cuda-acceptance.md) | Treat CUDA as optional and require host error checking |
